LESTARA TRAVEL — PHASE 1 WEBSITE
================================

FILES
- index.html: complete responsive bilingual website (English / Tetum)

WHAT WORKS
- Mobile-friendly travel agency homepage
- English / Tetum language toggle
- Flight, boat/ferry, bus/train and tour quick enquiry form
- Contact enquiry form
- Both forms open WhatsApp with a prefilled message to +670 7558 6003
- Services: tickets, tours, visa assistance, car rental, motorbike rental
- Email and social links

IMPORTANT BEFORE PUBLISHING
1. Confirm the phone number +670 7558 6003 is registered with WhatsApp.
2. Verify all social profile URLs. The Facebook link currently goes to Facebook home because a page URL was not provided.
3. Review the Tetum translations and all business details before launch.
4. This is an enquiry website, not a live ticketing engine. It does not check fares, issue tickets, process payments, or confirm bookings.
5. Images and Google Fonts are loaded from external services, so visitors need internet access to load them.

HOW TO PUBLISH FREE WITH NETLIFY (MANUAL DEPLOY)
1. Extract the ZIP file on your computer. Make sure index.html is at the top level of the folder you upload.
2. Open https://app.netlify.com/drop in a browser and sign in or create a Netlify account if prompted.
3. Drag the extracted folder (or the folder containing index.html) into the deploy area.
4. Wait for the upload and deployment to finish. Netlify will show a public URL, usually ending in netlify.app.
5. Open the URL on your phone and test the language switch, enquiry form, WhatsApp link, email link and social links.
6. You can change the generated site name in Netlify site settings if the name is available. Custom domains can be connected later.

ALTERNATIVE FREE HOSTING
Cloudflare Pages and GitHub Pages are also options, but their setup steps may differ. Free-plan terms can change; check the host's current terms before publishing.
